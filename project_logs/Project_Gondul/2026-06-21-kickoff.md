# 2026-06-21 - Project Göndul Kickoff

## Trigger idea

The project began from a parts-box review:

- One early Phantom with an intact NAZA box
- One rare Phanvick folding Phantom-to-Mavic-style conversion frame
- Three Phantom donor/reference aircraft: Phantom 1, Phantom 2, Phantom 3

The original thought was to build the NAZA hardware into the pseudo-Mavic frame and use it to test add-on concepts before risking smaller DJI Mini aircraft.

## Concept shift

The Phanvick platform is now being treated as a potential **mother ship / comm node** for the Drone Libre ecosystem.

Working project name: **Göndul**

Role:

- Queen-bee aircraft
- Airborne command node
- Communications relay
- Swarm coordinator
- Experimental avionics mule

## Naming note

Göndul is a named Valkyrie. The name was selected because it fits the mission: observe the field, guide the swarm, relay information, and help bring the smaller aircraft home.

Radio-friendly pronunciation: **GURN-dool**.

## Initial design decision

Start with the Phantom 1 / NAZA donor path because it is more open and serviceable than later integrated DJI systems.

The Phantom 3 may be useful later for an authentic Phanvick-era conversion, but the NAZA path is better for Drone Libre test work.

## Immediate build philosophy

1. Preserve and document the original Phanvick body before cutting anything.
2. Build a stock/simple flying mule first.
3. Add passive instrumentation second.
4. Add relay functions third.
5. Add coordination/swarm functions only after the aircraft is proven.

## Risks noted

- Rare shell should not be damaged before mold/measurement work.
- Payload electronics must not interfere with the flight controller.
- CG changes from add-ons need to be measured.
- RF payloads need antenna separation from GPS/compass and receiver systems.
