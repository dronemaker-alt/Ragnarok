# 2026-06-21 - Photo Session and Airframe Study

## Objective

Document the rare Phanvick conversion kit and evaluate possible integration paths with existing Jotun carbon-frame hardware.

## Significant findings

### Phanvick battery integration

The Phanvick does not simply imitate a Mavic externally.

Inspection revealed:

- Integrated Phantom battery compartment
- Phantom battery retention system
- Dedicated battery guide rails
- Structural battery mounting architecture

Conclusion:

The original designer intended continued use of Phantom batteries and solved battery integration as part of the airframe design.

## Internal structure observations

The shell contains significant molded structure:

- Honeycomb reinforcement
- Structural ribs
- Wire-routing provisions
- Dedicated internal mounting locations

Conclusion:

The kit appears substantially more engineered than a cosmetic conversion.

## Jotun frame compatibility study

A Jotun carbon frame was used for dry-fit studies.

Important discovery:

The Jotun frame geometry was originally designed around Phantom board dimensions.

When the Phanvick shell was placed over the frame, proportions appeared unexpectedly natural.

The shell, battery volume, center-frame dimensions, and expected electronics volume appear compatible.

## Carbon-tube concept study

16 mm carbon-tube arm concepts were evaluated visually.

Potential advantages:

- Easier replacement
- Improved stiffness
- Internal wire routing
- Simplified fabrication
- Reduced dependence on rare original arm components

Decision:

Preserve original Phanvick configuration first.

Carbon-tube arm concepts are deferred to future variants.

## Göndul architecture evolution

Original idea:

- Build a pseudo-Mavic from Phantom hardware.

Current concept:

- Airborne command node
- Relay aircraft
- Swarm coordinator
- Drone Libre avionics laboratory

The aircraft is now considered a 'Queen Bee' platform.

## Development strategy selected

### Göndul-A

Historical/reference build.

Goals:

- Preserve original Phanvick architecture.
- Fly and document the original concept.
- Establish performance baseline.

### Göndul-B

Composite-development airframe.

Goals:

- Molded shell
- Carbon/fiberglass experimentation
- Service hatches
- Alternate arm architecture
- Expanded avionics volume

### Göndul-C

Purpose-built Drone Libre command aircraft.

Goals:

- H743 architecture
- Companion computer integration
- Relay functions
- ADS-B integration
- Swarm coordination experimentation

## Mold discussion notes

Current recommendation:

1. Build and fly Göndul-A first.
2. Document required changes.
3. Modify master shell only after lessons learned.
4. Create female molds from validated geometry.

Reasoning:

The aircraft should reveal required changes before mold creation.
