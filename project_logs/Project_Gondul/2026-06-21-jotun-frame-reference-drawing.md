# Jotun Frame Reference Drawing

Date: 2026-06-21

## Source

Printed dimensional reference drawing for the carbon-tube Jotun frame used during Göndul dry-fit studies.

## Observations

The frame provides multiple standard flight-controller mounting options:

- 20 mm pattern
- 25 mm pattern
- 30.5 mm pattern

This supports integration of modern flight controllers including the H743 development hardware.

## Importance to Göndul

The drawing confirms that the Jotun frame was designed around conventional quadcopter electronics rather than proprietary Phantom hardware.

During dry-fit testing the Phanvick shell was found to fit naturally over the Jotun frame geometry.

This establishes the Jotun frame as the current baseline development chassis for Göndul-A and subsequent variants.

## Configuration Notes

Current evaluation hardware:

- Carbon tube arms
- Carbon center plates
- Phantom-derived Phanvick shell
- Phantom battery architecture
- H743 planned future integration

## Design Insight

A significant realization during testing was that the frame had previously been assembled backwards relative to the original manufacturer's intended orientation.

When re-evaluated against the Phanvick shell geometry, the resulting proportions appeared more aircraft-like and suggested a natural integration path between the shell and frame.
