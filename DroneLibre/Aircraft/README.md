# Drone Libre Aircraft Records

This folder holds one maintenance / engineering record per aircraft.

The purpose is to treat every crashed, donated, repaired, or experimental drone like an aircraft record instead of a random parts donor.

## Naming Convention

```text
DL-###-Nickname.md
```

Examples:

```text
DL-001-CFIT.md
DL-002-Davey-Jones.md
DL-003-Mini2-Yaw-Arm.md
```

## Aircraft Status Terms

```text
Intake - received but not inspected
Inspection - teardown / evaluation in progress
Repair - repair work underway
Ground Test - powers up and ready for bench testing
Flight Test - ready for controlled flight validation
Operational - repaired and usable
Donor - parts source only
Archived - record preserved, no active repair planned
```

## Minimum Record Requirements

Each aircraft record should include:

- Identification
- Source and acquisition notes
- Reported condition
- Actual observed condition
- Accident classification
- Electrical checks
- Gimbal checks
- Motor / ESC checks
- Repair plan
- Parts required
- Final disposition
