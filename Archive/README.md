# Drone Libre Archive

This archive records CAD references, measurement notes, and design observations for Drone Libre research and prototype development.

## Purpose

Drone Libre is an open UAV development effort focused on repairable, modifiable, builder-accessible drone platforms. This archive is intended to keep useful mechanical references organized for future design work.

The current focus is Mini-class and Mavic-inspired airframes, modular companion electronics, Remote ID integration, folding-arm mechanisms, and printable or composite airframe development.

## Archive Status

Research / Reference / Prototype Support

These notes are not flight-ready release packages. They are baseline references for study, measurement, and future original Drone Libre designs.

## Current Archive Areas

- VZ Mavic Clone reference project
- DJI Mini 2 dimensional reference model
- Legacy printable gimbal concepts
- Folding arm and pivot mechanisms
- Phanvick / Gondul shell measurements and body reconstruction
- Mini Libre and Gondul airframe concepts
